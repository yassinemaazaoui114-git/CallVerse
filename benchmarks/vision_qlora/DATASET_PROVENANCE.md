# CallVerse vision dataset — provenance and licence report

Built 2026-11-01. 150 photos, **150 real photographs, 0 synthetic / AI-generated images.**
Every photo was looked at by eye (contact sheets) before its label and description were written.
The customer messages attached to 133 of the photos are **written examples (AI-generated by Claude)**, marked as
such in `manifest.jsonl`; no real customer text matches these photos. They are used only for the late-fusion
tests in CallVerse, never as training input for the vision model.

Git keeps only `manifest.jsonl` (source + pinned revision + sha256 + labels). The photos are downloaded again by
`build_dataset.py` (or by the Kaggle notebook), because the CallVerse repository is **public** and several
sources do not grant redistribution. Nothing below was obtained by bypassing a gate, a login or a licence page.

## Sources checked and NOT used

| Source | Why not |
|---|---|
| Amazon **Kaputt** (`amazon/kaputt`, HF) | gated (accept-terms + login). Not bypassed. Would be the best e-commerce damage source if Yassine accepts the terms on his own account. |
| Delonix hotel-room quality (HF) | public part = screenshots of chat collages of under-bed inspections, not customer photos; the "unqualified" images are only in a GitHub release (not reachable). |
| RIstay garment holes (HF, CC BY 4.0) | holes are a few pixels wide: invisible at the model's input size. Training on them would teach the model to "see" damage that is not visible. **So torn clothing has no real example (gap).** |
| MVTec AD / VisA | industrial close-ups, not customer-style; MVTec is CC BY-NC-SA. Not relevant enough. |
| HassanBinAli/Damaged_Parcel_boxes | contains only image URL strings, no images. |
| 34data AI-generated damaged phone screens | synthetic; real photos were available. |
| kouge0510 broken packages | images only on Baidu Pan (not reachable), model weights only in git. |
| Kaggle, Roboflow Universe, Wikimedia Commons, Openverse, Flickr | blocked by this sandbox's network policy (not a licence decision). Kaggle has more "messy room" / "damaged package" sets worth checking later. |
